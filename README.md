# Calculadora de Overclock GPU

Calculadora web de overclock y undervolt para 35 tarjetas gráficas: GeForce RTX 50/40/30, GTX 16, Radeon RX 9000/7000/6000 e Intel Arc.

Devuelve valores de arranque ajustados a seis variables — modelo, objetivo, refrigeración, flujo del gabinete, temperatura ambiente y margen de la fuente — junto con la curva tensión/frecuencia, un protocolo de validación y una tabla de diagnóstico.

Cada fabricante usa sus propios controles: offsets en MHz para NVIDIA (MSI Afterburner), frecuencia máxima y tope de voltaje para AMD (Adrenalin), porcentaje de boost para Intel.


## Aviso

Los valores son un punto de partida calculado, no un perfil verificado. La lotería del silicio es real: dos unidades del mismo modelo pueden diferir 150 MHz al mismo voltaje. Valida siempre antes de dar un perfil por bueno.
